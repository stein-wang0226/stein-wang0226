**Research Interests**

> *"The most interesting problems live at the intersection of paradigms — where autoregressive meets diffusion, where language meets vision, where training meets inference."*

- **LLMs & Agents** — post-training, tool use, multi-turn reasoning (Thought → Action → Observation), RL for agents
- **Diffusion Language Models** — locality-aware architectures, training stability, inductive-bias / task-structure relationship
- **AI4S** — protein / small-molecule modeling, unified evaluation, Protein Agents
- **Multimodal LLMs** — unified understanding & generation, protein ↔ text bidirectional modeling
- **Graph Neural Networks** — dynamic-graph reasoning, fraud detection on spatio-temporal graphs
